# shag1 — автоматизация аттестационных периодов myschool.05edu.ru

CLI-утилита на Python для работы с **аттестационными периодами** в электронном
журнале «Моя школа» (платформа МЭШ, `myschool.05edu.ru`):

- просмотр графиков аттестационных периодов (ГАП) школы;
- создание **промежуточного аттестационного периода** (промежуточная аттестация);
- привязка графика к учебным группам.

Эндпоинты и модель данных восстановлены из HAR-дампа реальной сессии —
подробный разбор в [`docs/api-notes.md`](docs/api-notes.md).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

Скопируйте пример конфига и впишите свои значения:

```bash
cp config.example.json config.json
```

Главное — заполнить `cookie` (сессия авторизации). Как получить:
откройте журнал в браузере → DevTools (F12) → вкладка **Network** → любой
запрос к `/api/...` → скопируйте заголовок **Cookie** целиком в `config.json`.

> `config.json` добавлен в `.gitignore` — он содержит вашу сессию и **не
> коммитится** в репозиторий. Cookie имеет ограниченный срок жизни: при
> ошибках 401/403 обновите его.

Остальные параметры (`profile_id`, `academic_year_id`, `school_id`,
`organization_id`, заголовки) заполнены значениями из разобранной сессии;
при необходимости замените их на свои.

Вместо файла можно использовать переменные окружения
(`MYSCHOOL_COOKIE`, `MYSCHOOL_PROFILE_ID`, `MYSCHOOL_ACADEMIC_YEAR_ID`, ...).

## Использование

Все изменяющие команды по умолчанию работают в режиме **предпросмотра**
(dry-run) — показывают, что будет отправлено, но ничего не меняют.
Для реального запроса добавьте флаг `--apply`.

```bash
# Список всех графиков аттестационных периодов (ГАП)
python -m myschool schedules

# Список учебных групп (например, 2 класс)
python -m myschool groups --class-level 2

# Создать промежуточный аттестационный период (сначала посмотреть тело)
python -m myschool create-period \
    --name "Промежуточная аттестация 2026-2027" \
    --period "Промежуточная,01.09.2026,26.05.2027"
# ...и выполнить реально:
python -m myschool create-period \
    --name "Промежуточная аттестация 2026-2027" \
    --period "Промежуточная,01.09.2026,26.05.2027" --apply

# Привязать график (ГАП id=16209) к конкретной группе
python -m myschool assign --schedule-id 16209 --group-id 2204671 --apply

# ...или ко всем группам уровня класса
python -m myschool assign --schedule-id 16209 --class-level 2 --all --apply
```

Период для `--period` задаётся как `Название,ДД.ММ.ГГГГ,ДД.ММ.ГГГГ`,
флаг можно повторять, чтобы добавить несколько периодов.

### Готовый сценарий: закрепить промежуточный период у 2–4 классов

`scripts/assign_intermediate_2_4.py` за один запуск проставляет график
аттестационных периодов всем группам 2, 3 и 4 классов. График ищется по
части названия (по умолчанию «промеж») либо задаётся явно через
`--schedule-id`. Группы, у которых график уже стоит, пропускаются
(можно переназначить с `--force`).

```bash
# предпросмотр (ничего не меняет):
python scripts/assign_intermediate_2_4.py --match "промеж"

# применить:
python scripts/assign_intermediate_2_4.py --match "промеж" --apply

# или явно по id графика:
python scripts/assign_intermediate_2_4.py --schedule-id 16209 --apply
```

Если по подстроке найдётся несколько графиков или ни одного — скрипт
покажет список доступных и попросит указать `--schedule-id`.

## Важно про создание периода

Запрос создания графика **не был зафиксирован в HAR** (записался только
метрик-гол `addAssessmentPeriodFormSaveClick`), поэтому путь и тело команды
`create-period` восстановлены по модели данных и помечены как
**предположительные**. Перед боевым применением проверьте реальный запрос
в DevTools (Network) при нажатии «Сохранить» в журнале и при необходимости
поправьте `myschool/client.py`. Команды `schedules`, `groups` и `assign`
подтверждены HAR и соответствуют реальному API.

## Оговорка

Утилита обращается к вашему рабочему аккаунту в журнале от вашего имени
(ваша сессия). Используйте её только для своей школы и своих данных,
в рамках ваших прав в системе.
